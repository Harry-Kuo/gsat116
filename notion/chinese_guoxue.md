## 一、月份別稱
- **孟、仲、季**：一年四季，每季三個月依序稱為孟、仲、季。例如孟春＝農曆一月，仲夏＝五月，季秋＝九月。
- **用花卉命名**：二月杏、三月桃、四月槐、五月榴、六月荷、八月桂、九月菊。

| 農曆 | 季節名 | 其他別稱 |
|---|---|---|
| 一月 | 孟春 | 正月、元月、初春 |
| 二月 | 仲春 | 杏月 |
| 三月 | 季春 | 暮春、桃月 |
| 四月 | 孟夏 | 槐月 |
| 五月 | 仲夏 | 榴月、蒲月（端午節家家戶戶在門上掛菖蒲） |
| 六月 | 季夏 | 荷月、暑月 |
| 七月 | 孟秋 | 瓜月、蘭月、蘭秋 |
| 八月 | 仲秋 | 桂月、壯月 |
| 九月 | 季秋 | 菊月、玄月、暮秋 |
| 十月 | 孟冬 | 陽月、良月、小春 |
| 十一月 | 仲冬 | 冬月、暢月 |
| 十二月 | 季冬 | 臘月、嘉平、除月 |

**每月的日子**：朔＝初一，望＝十五，既望＝十六，晦＝每月最後一天。〈赤壁賦〉「壬戌之秋，七月既望」就是七月十六日。

**看詩句認節日**

| 節日 | 詩句 |
|---|---|
| 春節 | 爆竹聲中一歲除，春風送暖入屠蘇。（王安石〈元日〉） |

| 清明 | 清明時節雨紛紛，路上行人欲斷魂。（杜牧〈清明〉） |

## 四、常見題辭
題辭要看**場合**（婚、生子、壽、喪、開業）和**對象**（男或女、醫生或老師）。

| 場合 | 題辭 |
|---|---|
| 結婚 | 百年好合、鳳凰于飛、琴瑟和鳴、珠聯璧合 |
| 女子出嫁 | 宜室宜家 |
| 生男孩 | 弄璋之喜（璋是玉器） |
| 生女孩 | 弄瓦之喜（瓦是紡織用的陶製紡錘） |
| 祝壽 | 福如東海、壽比南山、松柏長青 |

## 五、謙敬詞

| 用法 | 例詞 |
|---|---|
| 「家」：對人謙稱自己的長輩親屬 | 家父（家嚴）、家母（家慈）、家兄 |
| 「舍」：對人謙稱自己年幼的親屬 | 舍弟、舍妹 |
| 謙稱自己的子女、妻子 | 小犬（犬子）、小女、拙荊、內人 |
| 「令」：尊稱別人的親屬 | 令尊、令堂、令兄、令郎、令嬡 |
| 「先」：稱已經過世的長輩 | 先父（先嚴、先考）、先母（先慈、先妣） |
| 自稱的謙詞 | 敝人、鄙人、愚 |
| 稱對方的敬詞 | 閣下、足下、賢弟 |

- 常見錯誤：「家」「舍」只用來稱自己的親屬，「令」只用來稱別人的親屬，所以不能說「我的令尊」。
- 〈項脊軒志〉的「先大母」（已故的祖母）、「先妣」（已故的母親），就是「先」的用法。

## 七、天干地支與時辰
- **十天干**：甲、乙、丙、丁、戊、己、庚、辛、壬、癸。
- **十二地支**：子、丑、寅、卯、辰、巳、午、未、申、酉、戌、亥，依序對應鼠、牛、虎、兔、龍、蛇、馬、羊、猴、雞、狗、豬。
- **干支紀年**：天干和地支依序相配，六十年一輪，稱為「一甲子」。〈赤壁賦〉的「壬戌」是西元 1082 年，〈鹿港乘桴記〉的「丙申兵火」是 1896 年，〈畫菊自序〉寫於庚寅年，也就是 1950 年。
- **十二時辰**：一天分成十二段，每段兩小時。〈晚遊六橋待月記〉「止午、未、申三時」，就是上午十一點到下午五點。

| 時辰 | 時間 | 時辰 | 時間 |
|---|---|---|---|
| 子 | 23:00–1:00 | 午 | 11:00–13:00 |
| 丑 | 1:00–3:00 | 未 | 13:00–15:00 |
| 寅 | 3:00–5:00 | 申 | 15:00–17:00 |
| 卯 | 5:00–7:00 | 酉 | 17:00–19:00 |
| 辰 | 7:00–9:00 | 戌 | 19:00–21:00 |
| 巳 | 9:00–11:00 | 亥 | 21:00–23:00 |

- **五更**：古代把夜晚分成五段，從晚上七點到清晨五點，每段兩小時；五更約是清晨三點到五點（〈虯髯客傳〉「其夜五更初」）。

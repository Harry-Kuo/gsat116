## 一、月份別稱
- **孟、仲、季**：一年四季，每季三個月依序稱為孟、仲、季。例如孟春＝農曆一月，仲夏＝五月，季秋＝九月。
- **用花卉命名**：二月杏、三月桃、四月槐、五月榴、六月荷、八月桂、九月菊。

| 農曆 | 季節名 | 其他別稱 |
|---|---|---|
| 一月 | 孟春 | 正月、元月、初春 |
| 二月 | 仲春 | 杏月 |
| 三月 | 季春 | 暮春、桃月 |
| 四月 | 孟夏 | 槐月 |
| 五月 | 仲夏 | 榴月、蒲月（端午節家家戶戶在門上掛菖蒲） |
| 六月 | 季夏 | 荷月、暑月 |
| 七月 | 孟秋 | 瓜月、蘭月、蘭秋 |
| 八月 | 仲秋 | 桂月、壯月 |
| 九月 | 季秋 | 菊月、玄月、暮秋 |
| 十月 | 孟冬 | 陽月、良月、小春 |
| 十一月 | 仲冬 | 冬月、暢月 |
| 十二月 | 季冬 | 臘月、嘉平、除月 |

**每月的日子**：朔＝初一，望＝十五，既望＝十六，晦＝每月最後一天。〈赤壁賦〉「壬戌之秋，七月既望」就是七月十六日。

## 五、謙敬詞

| 用法 | 例詞 |
|---|---|
| 「家」：對人謙稱自己的長輩親屬 | 家父（家嚴）、家母（家慈）、家兄 |
| 「舍」：對人謙稱自己年幼的親屬 | 舍弟、舍妹 |
| 謙稱自己的子女、妻子 | 小犬（犬子）、小女、拙荊、內人 |
| 「令」：尊稱別人的親屬 | 令尊、令堂、令兄、令郎、令嬡 |
| 「先」：稱已經過世的長輩 | 先父（先嚴、先考）、先母（先慈、先妣） |
| 自稱的謙詞 | 敝人、鄙人、愚 |
| 稱對方的敬詞 | 閣下、足下、賢弟 |

- 常見錯誤：「家」「舍」只用來稱自己的親屬，「令」只用來稱別人的親屬，所以不能說「我的令尊」。
- 〈項脊軒志〉的「先大母」（已故的祖母）、「先妣」（已故的母親），就是「先」的用法。

## 七、天干地支與時辰
- **十天干**：甲、乙、丙、丁、戊、己、庚、辛、壬、癸。
- **十二地支**：子、丑、寅、卯、辰、巳、午、未、申、酉、戌、亥，依序對應鼠、牛、虎、兔、龍、蛇、馬、羊、猴、雞、狗、豬。
- **干支紀年**：天干和地支依序相配，六十年一輪，稱為「一甲子」。〈赤壁賦〉的「壬戌」是西元 1082 年，〈鹿港乘桴記〉的「丙申兵火」是 1896 年，〈畫菊自序〉寫於庚寅年，也就是 1950 年。
- **十二時辰**：一天分成十二段，每段兩小時。〈晚遊六橋待月記〉「止午、未、申三時」，就是上午十一點到下午五點。

| 時辰 | 時間 | 時辰 | 時間 |
|---|---|---|---|
| 子 | 23:00–1:00 | 午 | 11:00–13:00 |
| 丑 | 1:00–3:00 | 未 | 13:00–15:00 |
| 寅 | 3:00–5:00 | 申 | 15:00–17:00 |
| 卯 | 5:00–7:00 | 酉 | 17:00–19:00 |
| 辰 | 7:00–9:00 | 戌 | 19:00–21:00 |
| 巳 | 9:00–11:00 | 亥 | 21:00–23:00 |

- **五更**：古代把夜晚分成五段，從晚上七點到清晨五點，每段兩小時；五更約是清晨三點到五點（〈虯髯客傳〉「其夜五更初」）。

## 八、六書
六書是古人分析漢字構造的六種條例：象形、指事、會意、形聲是造字的方法，轉注、假借是用字的方法。

| 六書 | 說明 | 例字 |
|---|---|---|
| 象形 | 畫出物體的形狀 | 日、月、山、水、人、魚 |
| 指事 | 用符號表示抽象的概念，或在象形字上加記號 | 上、下、本（木下加一，指樹根）、末（木上加一，指樹梢）、刃（刀口加一點） |
| 會意 | 合併兩個以上的字，組成新的意思 | 武（止戈）、信（人言）、休（人倚木）、明（日月）、森 |
| 形聲 | 一部分表示意義（形符），一部分表示讀音（聲符） | 江、河（水為形，工、可為聲）；問、聞（門為聲） |
| 轉注 | 部首相同、意義相通的字可以互相解釋 | 考、老 |
| 假借 | 本來沒有這個字，借用讀音相同的字來表示 | 其（本義是畚箕，借作代詞）、來（本義是麥，借作來去的來）、北（本義是相背，借作方位） |

- 形聲字最多，約占漢字的八成以上。形符與聲符的位置不固定：左形右聲（江）、右形左聲（鳩）、上形下聲（草）、下形上聲（婆）、外形內聲（圃）、內形外聲（問）。
- 聲符的讀音經過長期演變，不一定和現在的讀音相同（例如「江」的聲符是「工」），所以字音題不能「有邊讀邊」。

## 九、修辭（表現手法）

| 修辭 | 說明 | 例句 |
|---|---|---|
| 譬喻 | 用具體、熟悉的事物比方另一件事物（明喻、暗喻、略喻、借喻） | 寄蜉蝣於天地，渺滄海之一粟。（蘇軾〈赤壁賦〉） |
| 轉化 | 把物當人寫（擬人）、把人當物寫（擬物），或把抽象的事物寫得具體（形象化） | 感時花濺淚，恨別鳥驚心。（杜甫〈春望〉） |
| 映襯 | 把相反或對立的事物並列，讓意思更鮮明 | 朱門酒肉臭，路有凍死骨。（杜甫〈自京赴奉先縣詠懷五百字〉） |
| 誇飾 | 刻意誇大或縮小 | 白髮三千丈，緣愁似箇長。（李白〈秋浦歌〉） |
| 借代 | 不直接說出事物，用相關的名稱代替 | 臣本布衣（布衣代平民，諸葛亮〈出師表〉） |
| 設問 | 用問句引起注意：提問（自問自答）、激問（答案在問題的反面）、懸問（只問不答） | 王侯將相寧有種乎？（激問，《史記．陳涉世家》） |
| 對偶 | 字數相等、詞性相對、句法相同的兩句並列 | 親賢臣，遠小人。（〈出師表〉） |
| 排比 | 三個以上結構相似的句子並列，加強語氣 | 洗手的時候，日子從水盆裡過去；吃飯的時候，日子從飯碗裡過去；默默時，便從凝然的雙眼前過去。（朱自清〈匆匆〉） |
| 層遞、頂真 | 層遞是依大小、輕重、先後一層層推進；頂真是用前一句的結尾當下一句的開頭 | 天時不如地利，地利不如人和。（《孟子》，兼有層遞與頂真） |
| 類疊 | 同一個字詞或句子重複使用（疊字、類字、疊句、類句） | 青青河畔草，鬱鬱園中柳。（〈古詩十九首〉） |
| 互文 | 上下文的意思互相補足，要合起來理解 | 秦時明月漢時關。（王昌齡〈出塞〉：秦漢時的明月、秦漢時的關） |
| 倒裝 | 故意顛倒文法上的順序 | 何陋之有？（劉禹錫〈陋室銘〉，即「有何陋」） |
| 雙關 | 一個詞同時兼顧兩種意思 | 東邊日出西邊雨，道是無晴卻有晴。（劉禹錫〈竹枝詞〉，「晴」雙關「情」） |
| 示現 | 把不在眼前的事物寫得如在眼前（追述過去、預言未來、懸想遠方） | 遙知兄弟登高處，遍插茱萸少一人。（王維〈九月九日憶山東兄弟〉，懸想） |
| 婉曲 | 不直接說明，用委婉的話表達 | 生孩六月，慈父見背。（李密〈陳情表〉，「見背」指父親過世） |
| 象徵 | 用具體的事物表現抽象的意義 | 松柏象徵堅貞，蓮象徵高潔 |

- 判斷修辭先看句子的「形式」（對偶、排比、類疊、頂真看句式），再看「內容」（譬喻、轉化、借代、誇飾看意思）；一句話可能同時用了好幾種修辭。

**詩歌格律**
- 近體詩：絕句 4 句、律詩 8 句（首聯、頷聯、頸聯、尾聯，頷聯與頸聯要對仗），有五言、七言；押平聲韻、一韻到底，講究平仄。
- 古體詩：句數不限、可以換韻，平仄比較自由（例如樂府詩、〈古詩十九首〉）。
- 詞：又稱詩餘、長短句，依詞牌填寫，通常分上下兩片（闋）。
- 曲：依曲牌填寫，可以加襯字、用口語；散曲用來清唱，雜劇用來演出。

## 十一、對聯
- 上下聯字數相等、詞性相對、句法相同、平仄相反；上聯最後一字是仄聲，下聯最後一字是平聲。
- 判斷平仄：國語的第一、二聲大多是平聲，第三、四聲是仄聲；但古代的入聲字（例如「一、十、白、竹、國」）在國語中有些讀成第一、二聲，在詩詞對聯中仍算仄聲。
- 判斷上下聯：先看最後一字的平仄，仄聲的是上聯；張貼時上聯在右（面對大門時的右手邊）、下聯在左。
- 題目常考：依內容判斷對聯適用的場合（行業、節慶、婚喪、名勝）或描寫的人物。
